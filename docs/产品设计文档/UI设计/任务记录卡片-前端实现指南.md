## 一、通用布局规范

### 1. 卡片基础样式

### 2. 双行布局结构

所有类型均采用双行布局：

```
┌─────────────────────────────────────────────────────────────────┐
│  [状态图标]  标题文本                                            │ ← 主行
│             [副行内容]                          [操作按钮 hover] │ ← 副行
└─────────────────────────────────────────────────────────────────┘
```

### 3. 主行样式（所有类型通用）

| 元素 | 样式 |
|------|------|
| 状态图标 | `width: 16px; height: 16px; font-size: 14px;` |
| 图标与标题间距 | `gap: 8px` |
| 标题 | `font-size: 14px; font-weight: 500; color: #374151;` |
| 标题截断 | `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` |

```css
.task-card-main-row {
    display: flex;
    align-items: center;
    gap: 8px;
}
```

### 4. 副行样式（所有类型通用）

| 元素 | 样式 |
|------|------|
| 左侧留白 | `padding-left: 24px` （与主行标题对齐）|
| 文本样式 | `font-size: 12px; color: #6b7280;` |
| 分隔符 | ` · ` （中点，两侧各一个空格）|

```css
.task-card-sub-row {
    display: flex;
    align-items: center;
    justify-content: space-between;
    padding-left: 24px;
    min-height: 20px;
}
```

### 5. 状态图标映射

| 状态值 | 图标 | 含义 |
|--------|------|------|
| `completed` | ✓ 或 ✅ | 已完成 |
| `analyzing` / `running` | ◐ 或 ⏳ | 分析中 |
| `terminated` | ✕ 或 ⏹️ | 已终止 |
| `failed` | ✕ 或 ❌ | 失败 |

### 6. 时间显示规则

```javascript
function formatTime(timestamp) {
    const now = new Date();
    const date = new Date(timestamp);

    // 今天：显示 HH:mm
    if (isSameDay(now, date)) {
        return format(date, 'HH:mm');  // 例：14:30
    }

    // 昨天：显示 昨天 HH:mm
    if (isYesterday(date)) {
        return `昨天 ${format(date, 'HH:mm')}`;  // 例：昨天 14:30
    }

    // 本年内：显示 MM-DD HH:mm
    if (isSameYear(now, date)) {
        return format(date, 'MM-DD HH:mm');  // 例：01-15 14:30
    }

    // 跨年：显示 YYYY-MM-DD HH:mm
    return format(date, 'YYYY-MM-DD HH:mm');  // 例：2024-12-20 14:30
}
```

### 1. 类型定义

| 属性 | 值 |
|------|-----|
| **组成** | 状态 + 标题 + 标签 + 统计 + 时间 + 终止/删除（互斥） |
| **状态模式** | 多状态（分析中、已完成、已终止） |
| **数据类型** | 代码类 |

### 2. 适用智能体

| 智能体 | 数据类型 | 标题来源示例 |
|--------|----------|--------------|
| AI漏洞猎人 | 代码类 | `spring-boot-demo`（仓库名）|

### 3. 状态与操作按钮对应关系

| 状态 | 图标 | 可用操作 | 说明 |
|------|------|----------|------|
| `analyzing` | ◐ | 终止 | 分析中，可终止任务 |

| `terminated` | ✕ | 删除 | 已终止，可删除记录 |

**重要**：终止和删除按钮**互斥**，永不同时出现！

### 8. 数据结构

```typescript
interface TypeCTask {
    id: string;
    name: string;                              // 标题（仓库名/目录名）
    status: 'analyzing' | 'completed' | 'terminated';
    source: 'local' | 'repo';                  // 来源：本地/仓库
    vulnCount: number | null;                  // 漏洞数量，分析中为 null
    time: string;                              // 创建时间
}
```

### 9. 副行文本拼接逻辑

```javascript
function buildSubRowText(task) {
    const parts = [];

    // 1. 标签
    parts.push(task.source === 'local' ? '本地' : '仓库');

    // 2. 统计
    if (task.status === 'analyzing') {
        parts.push('漏洞 --');
    } else {
        parts.push(`漏洞 ${task.vulnCount} 个`);
    }

    // 3. 时间
    parts.push(formatTime(task.time));

    return parts.join(' · ');
}
```
